# Demonstration status

> **Research and educational use only. Not for clinical diagnostic use, patient
> care, or treatment decisions.**

No disease-specific demonstration in this directory is a validated clinical or
scientific release artifact. The current package may return `BUNDLE_UNAVAILABLE`
until a compatible controlled signed catalog is supplied.

Use only the de-identified, status-preserving workflow described in
[onboarding](../../../docs/onboarding.md). Do not treat a demonstration as proof
of a diagnosis, prognosis, eligibility, counseling position, or treatment.

See [known limits](../../../docs/known-limits.md) and the
[capability matrix](../../../docs/release/capabilities.md).
