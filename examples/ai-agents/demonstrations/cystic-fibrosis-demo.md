# Cystic fibrosis demonstration status

> **Research and educational use only. Not for clinical diagnostic use, patient
> care, or treatment decisions.**

This historical disease-specific example is unavailable as a supported release
demonstration. It must not be read as a diagnostic assertion, clinical
classification, counseling statement, or treatment implication.

The current Python workflow accepts only supported de-identified research inputs
and reports structured status. Without a compatible controlled signed catalog,
classification returns `BUNDLE_UNAVAILABLE` rather than a result. Do not fill
that gap with legacy payloads, public labels, or model-generated content.

For the current workflow, see [agent integration](../README.md),
[onboarding](../../../docs/onboarding.md), and
[known limits](../../../docs/known-limits.md).
