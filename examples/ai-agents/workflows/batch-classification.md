# Batch classification example status

> **Research and educational use only. Not for clinical diagnostic use, patient
> care, or treatment decisions.**

This legacy batch example is unavailable as a supported release procedure. The
current routine MCP contract is scoped to one classification workflow and does
not expose a legacy low-level batch evidence-query chain.

Do not convert unavailable bundle/catalog state into synthetic batch output.
For a supported request, preserve each structured status separately and do not
merge degraded, conflict, missing-context, or failed responses into a
classification summary.

See [agent workflow examples](README.md),
[onboarding](../../../docs/onboarding.md), and the
[capability matrix](../../../docs/release/capabilities.md).
